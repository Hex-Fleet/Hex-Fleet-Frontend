# HexFleet Frontend

Next.js frontend for HexFleet, using Tailwind CSS, Lenis, and GSAP.

```bash
npm install
Copy-Item .env.example .env.local
npm run dev
```

Runs at http://localhost:3000.

For Vercel production, configure:

```env
NEXT_PUBLIC_API_URL=https://git-pipeline.metatronhost.in/hex-fleet
```
